# CMOS Inverter VTC Analysis

This folder contains the mathematical derivations and plotted Voltage Transfer Characteristic (VTC) curves for 5 different CMOS inverter scenarios.

**Included calculations for each scenario:**
* Logic Rails ($V_{OH}$, $V_{OL}$)
* Threshold Points ($V_{IH}$, $V_{IL}$)
* Switching Threshold ($V_M$)
* Noise Margins ($NM_L$, $NM_H$)
* Propagation Delay ($t_{pHL}$, $t_{pLH}$)
